# Glissando sample music

Tracks a user can pick for a slideshow without bringing their own. The app downloads a track
when it is picked and stores it in the slideshow like the user's own music, so every export
(.glissando file, web page, video) carries it.

Put the tracks in this folder (MP3, M4A or Ogg/Opus; one file per track).
