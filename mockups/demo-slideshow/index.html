Demo slideshow

The hosted site (polandy.github.io/glissando) offers a "Watch demo" so anyone can see Glissando play before installing. Two placements to compare; click through every state in each frame.

How it works: the demo pictures are fetched at runtime from polandy.github.io/glissando-assets/demo/. They are never stored in the app repo and the demo is not saved to the library. The credit line shows while it plays. Offline, the button is disabled and a toast explains why. (Gradients here stand in for pictures.)

Variant A: third button on the empty start screen

A quiet ghost button under "Open .glissando file". The first thing a visitor with an empty library can try.

Variant B: "Watch demo" card in the library

The card sits at the end of the grid, after "New slideshow", so a visitor with slideshows can still find it. Its cover is a play icon on the brand gradient.
