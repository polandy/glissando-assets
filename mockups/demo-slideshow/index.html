Demo slideshow

On the public install at polandy.github.io/glissando only — never on a self-hosted one — an empty library's start screen offers a quiet third button, "Load demo slideshow", under "New slideshow" and "Open .glissando file". Tapping it downloads a .glissando file from the assets site and opens it through the normal file-import path, landing on "Glissando demo": from then on it is an ordinary slideshow in the library — playable, editable, deletable, and offline once loaded.

How it works: the button only shows while the library is empty and only on the hosted install; delete the demo and, if the library is empty again, the button comes back. It downloads the demo file from polandy.github.io/glissando-assets/demo/ and imports it exactly as "Open .glissando file" would, so nothing about the result is special-cased. The pictures are © the owner; a small credit for the pictures and music shows while the demo plays. (Gradients here stand in for pictures.)
