Set the pace with no music yet

Today, a slideshow without music opens the music editor to only its empty state — so when the slideshow has no mood's own tempo either, there is nowhere to set how long each picture stays. After this change, the "Picture length" section shows below the empty-state card: under a mood, its line and a way to leave it for the slideshow's own pace; under Custom, the seconds-per-picture stepper, live, with no "Fill the music" choice since there is no music to fill.

What's decided

  • The empty state (disc icon, "No music yet", why-text, Add a song) is unchanged.
  • Below it, the main column also shows Picture length: under a mood, its "Picture times are set by the mood …" line without a beat count and a Set them yourself ghost button; under Custom, no radiogroup (there is no music for "Fill the music" to fill), just "About {n} s each" and the live seconds stepper (2–15 s, half-second steps).
  • Set them yourself switches the slideshow to Custom at 7 s and shows the toast "Mood is now Custom" with Undo, matching the mood screen's own toast; Undo returns to Calm.
  • On desktop the section sits in the main column, under the empty-state card — the music editor's side panel never appears with no music, so there is nowhere else for it to go.
