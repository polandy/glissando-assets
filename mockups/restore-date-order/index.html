Sort by date again

Mockup. After a shuffle or a move, one control puts every picture back in capture-date order. Try Shuffle (or drag a tile onto another, or use "Move a picture" on a phone), then bring the date order back. The date painted on each picture is a mockup aid; the real tiles carry no label.

Pictures

What it does

Shuffle and every move (Earlier, Later, Move to, a drag) make the order the user's own; the order line then reads "Own order" and automatic chapters switch off. Nothing so far leads back. Sort by date puts every picture in capture-date order again: the order line returns to "Sorted by capture date" (in the pictures step of a new slideshow: "Capture order"), automatic chapters come back on, and pictures added later are sorted in by date again.

  • It shows only while the order is the user's own; in date order there is nothing to restore.
  • Moves made by hand go too, since a shuffle and a move are one order. A toast "12 pictures sorted by capture date" with Undo brings the own order back, as Shuffle's Undo does.
  • The tiles glide to their places (not with reduced motion), like after a shuffle.
  • The same control in the slideshow editor and in the pictures step of a new slideshow.

Variants

A · Button beside Shuffle. "Sort by date" appears in the strip head next to Shuffle while the order is your own. Easy to find; on a phone the button row gets a fourth button and may wrap.
B · Link in the order line. The order line reads "Own order · Sort by date"; it takes the place of the "Drag to reorder" hint. No extra button; quieter and sits where the order is described, but a link is easier to overlook.
C · Order menu. Shuffle becomes "Order", a menu with "Shuffle" and "Sort by capture date" (disabled, with a check, while already sorted). Keeps the head as it is, but Shuffle is one tap further away.
Words. "Sort by date" mirrors the order line "Sorted by capture date". The glossary's "Back to automatic" was considered, but the order line never calls the date order "Automatic", so it would introduce a second name.
